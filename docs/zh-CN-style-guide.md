# 简体中文界面用语规范

本 Fork 按中国大陆常见记账习惯维护简体中文。文案按实际界面用途翻译，不逐词套用字典。

## 常用术语

| 原文及用途                                  | 中文                                           |
| ------------------------------------------- | ---------------------------------------------- |
| Account（现金、银行卡等）                   | 账户                                           |
| Account（登录身份）                         | 账号；删除登录身份称“注销账号”                 |
| Payee（同时用于收款和付款）                 | 收付款方                                       |
| Category / account category                 | 分类 / 账户类型                                |
| Base currency / display currency            | 本位币 / 显示币种                              |
| Tracker / budget / budget line              | 收支追踪 / 预算 / 预算项                       |
| Recurring payments（同时可记录收入）        | 定期收支                                       |
| Pending / booked（银行交易）                | 待入账 / 已入账                                |
| Out of wallet                               | 账外账户；资金动作称“账外转账”                 |
| Rollover / surplus / overspending           | 结转 / 结余 / 超支                             |
| Principal / interest / APR                  | 本金 / 利息 / 年利率（APR）                    |
| Security（投资品种） / Security（登录设置） | 证券 / 账号安全                                |

## 界面风格

- 按钮使用“创建、保存、移除、关闭、忽略”等明确动词，不写“创造、解雇”等直译。
- 表单 Optional 用“选填”；授权项 Optional 用“可选授权”。
- 优先省略无意义的人称，必要时使用“你”。避免“你可以在这里……”等冗长开场。
- 区分“移除关联”和“删除数据”。删除、清空和注销提示必须说明保留内容及是否可恢复。
- 同一词按业务语境处理：存入不是订金、贷款本金不是校长、自动不是汽车、预算项不是线路、财务自由不是消防。
- 货币和日期示例必须符合实际输入解析器支持的格式，不为了本地化改写成软件不接受的示例。
- 品牌、AI 模型标识、服务商名保留官方拼写，如 Monobank、Enable Banking、LunchFlow、Ollama、Microsoft Money。
- API 变量、链接、占位符、消息格式和复数分支不改动；以 scripts/check-chinese.mjs 校验。
- 前端文案与后端错误统一术语。不要运行批量机器翻译覆盖人工校订结果。

## 本次语境校订

对主导航、创建账户、收支表单、多账户付款、拆分与退款、预算结转、储蓄目标、贷款、投资及私募、AI 与 MCP、安全与数据清理等进行校订。

MCP 说明按实际授权流程描述，权限取决于用户选择，而不是笼统称为只读。表单移除付款账户表示移除分摊记录，不是删除整个账户。
